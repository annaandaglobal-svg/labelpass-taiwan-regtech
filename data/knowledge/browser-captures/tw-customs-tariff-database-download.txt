Tariff Database Download (通關服務 / 免證通關服務). Downloadable datasets:
(1) Tariff Schedule (xls / pdf / ods)
(2) CCC Code and Description of Goods (txt / pdf)
(3) By Chapters
(4) Application for Import Goods Advance Tariff Rulings (doc / pdf / odt)
(5) Tariff No. and Description of Goods (txt / pdf)
(6) a. Schedule of Tariff Concession for FTA (xls / pdf / ods); b. Schedule of Tariff Concession for ITA (xls / pdf / ods)
(7) Correlation Table between HS2012 and HS2017 versions of the Tariff Number (xls / pdf / ods)

Use this to look up the duty rate for an 11-digit CCC code and to check FTA/ITA preferential tariff concessions. Copyright Customs Administration, R.O.C.
