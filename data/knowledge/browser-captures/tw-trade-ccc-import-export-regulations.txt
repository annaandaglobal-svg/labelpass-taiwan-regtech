Import and Export Regulations query (CCC).
Search by Commodity Code:
- Single commodity code, commodity code range, or Import CCC code (up to 5 HS/CCC items).
- HS code: 2 to 6 digits (e.g., 01, 2001, 740729).
- CCC code: Standard Classification of Commodities of the Republic of China (中華民國商品標準分類), up to 10 digits (e.g., 0203120000, 2207101010). Full CCC is 11 digits (10-digit tariff classification + 1 check digit).
- Commodity Description: partial description search (e.g., fish, bovine animals, chemical).
- Regulation codes (輸入規定 / 輸出規定): choose Import or Export type then key a 3-digit code, e.g., 111, 401, 272, C01, MW0.

This platform maps a CCC code to its Import Regulation (輸入規定) / Export Regulation codes, which determine whether an import permit, inspection (e.g., F01 food import inspection by TFDA), or quarantine is required. Confirm the exact 11-digit CCC and regulation codes here for each product before customs clearance.
